# 个人工作日报详情格式

## 标题

`{department}{person_name}工作日报 {YYYY年MM月DD日}`

## 1. 核心工作与成果

每条事项写清：

- 工作事项
- 本期完成内容
- 核心成果
- 交付物
- 相关文档/会议纪要
- 业务价值
- 当前状态

推荐表达：完成了什么工作 + 交付了什么内容 + 形成了什么成果 + 产生了什么价值。

如果该事项产生或关联了飞书文档、会议纪要、妙记或其他交付物链接，必须在“相关文档/会议纪要”中附上名称和链接；没有明确链接证据时写“无明确证据”，不要省略该项。

## 2. 协同、风险与所需支持

- 事项描述
- 事项类型
- 协同对象/责任人
- 当前进展
- 影响范围
- 需要的支持
- 期望完成时间

## 3. AI提效与知识资产沉淀

写清 AI 做了什么、产生了什么效果、形成了什么可复用资产。

- AI/自动化应用场景
- 使用的 Skill 或 Workflow
- 本期优化内容
- 节省时间/提升效率
- 形成的文档或链接
- 是否具备复用价值
- 建议沉淀类型
- 后续优化计划

## 4. 未完成事项/代办/明日计划

- 重点工作事项
- 预期成果
- 计划交付物
- 优先级
- 计划完成时间
- 所需协同或资源

## 5. 重要文档与链接

只放筛选后值得进入部门知识沉淀的高价值文档。不要把会议纪要、妙记、普通过程文档或所有关联文档全量放入本节，除非它们已经整理成可复用方法论、标准流程、项目复盘、关键方案或正式交付物。

- 文档名称
- 文档链接
- 文档分类
- 应当存储知识库位

如果当天没有明确值得沉淀的文档，写“无明确需要沉淀的重要文档”，不要为了凑数放入普通会议纪要或运行证据。
